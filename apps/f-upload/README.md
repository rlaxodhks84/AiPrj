# F. 파일 업로드 절세 분석 (프로토타입)

홈택스에서 내려받은 엑셀/CSV/PDF를 Claude(`claude-opus-5-5`)가 분석해 절세 포인트 리포트를 만든다.
세액 계산은 LLM이 아니라 `packages/tax-engine`의 코드가 한다.

## 실행

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."     # 또는 .env 사용 (커밋 금지)
npm run f -- --dry-run input/              # 전송될 내용(마스킹 결과) 먼저 확인
npm run f -- --year 2025 --note "일반과세자, 온라인 소매, 2023년 개업" input/
```

결과: `out/report-*.md`, `out/report-*.json` (`input/`, `out/`은 gitignore 처리됨)

## 홈택스에서 받아올 자료 예시
- 부가세: 전자세금계산서 매출/매입 목록, 사업용 신용카드 매입내역, 현금영수증 매입/매출, 신용카드 매출자료
- 종소세: 종합소득세 신고도움서비스(안내유형·경비율·기납부세액), 지급명세서, 사업용 카드 연간 내역

## 개인정보
- 텍스트(엑셀·CSV)는 주민번호·카드번호·계좌/사업자번호를 마스킹한 뒤 전송한다.
- **PDF·이미지는 마스킹 없이 원본이 전송된다.** 가능하면 엑셀로 받을 것.
