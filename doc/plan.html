계획안

무엇을, 왜, 어떤 순서로 만드는가 · 2026-11-24 기준

1. 목표

홈택스에 내가 직접 로그인한 뒤, 홈택스 자료와 화면을 바탕으로 Claude가 부가세·종소세 절세 포인트를 찾아주는 개인용 어시스턴트를 만든다. 어시스턴트는 근거와 예상 절세액, 홈택스 입력 위치를 알려주고, 신고서 제출은 내가 직접 한다.

2. 범위

포함

  • 개인사업자 본인 (일반·간이과세자)
  • 부가가치세: 매입세액 공제 누락, 불공제 오분류, 의제매입, 카드매출 세액공제, 간이/일반 유불리
  • 종합소득세: 장부 vs 추계 비교, 노란우산·연금저축·IRP, 중소기업 특별세액감면, 창업 감면, 인적공제, 기납부세액

제외

  • 타인 대리 신고 (세무사법 이슈)
  • 신고서 자동 제출
  • 일반 사용자 배포, 회원 관리
  • 법인세, 원천세 (추후 검토)
  • 공동인증서 보관

4. 로드맵

신뢰도는 데이터를 어디서 얻느냐로 정했다. 공식 파일 > 화면 DOM > 스크린샷 순이다.

F. 파일 업로드 분석 구현 완료 API 실호출 미검증

홈택스에서 내려받은 엑셀·CSV·PDF를 분석해 절세 리포트를 만든다. 화면 자동화가 없어 가장 견고하다.
남은 일: 실제 홈택스 자료로 실행, 리포트 품질 점검, 세율표 최신 고시 확인.

B. 로컬 에이전트 + CDP 연결 다음

내가 로그인한 Chrome에 Playwright(connectOverCDP)로 붙어 현재 홈택스 화면을 읽는다. 터미널에서 대화한다.
핵심 산출물: 홈택스 메뉴별 화면 어댑터(DOM → JSON). A에서 그대로 재사용한다.

A. Chrome 확장 Side Panel 예정

홈택스 옆에 채팅 패널을 띄운다. 입력할 위치를 강조하고, 입력값은 내가 승인한 뒤에만 넣는다.
혼자 쓰므로 압축 해제 확장으로 로드하고, 스토어에는 배포하지 않는다.

C. Computer use (스크린샷 기반) 예정

DOM 파싱이 안 되는 화면을 보완하는 용도로 쓴다. 읽기 전용으로만 사용하고 클릭 권한은 주지 않는다.
