3. 세금 엔진 (packages/tax-engine)

LLM은 세액을 직접 계산하지 않는다. 아래 함수만 도구로 호출한다. 세율은 rates.ts에 데이터로 분리되어 있다.

함수입력출력 / 규칙
calcIncomeTax과세표준, 귀속연도산출세액, 지방소득세(10%), 한계세율. 기본세율 8단계(6~45%)와 누진공제 적용. 검증 연도(2025) 이후면 경고
compareIncomeTax전/후 과세표준절세액(종소세+지방소득세 차이). 공제 추가 전후, 장부 vs 추계 비교용
calcGeneralVat과세매출 공급가액, 공제 매입세액, 카드매출 발행액 등매출세액 10% − 매입세액 − 카드발행공제(1.3%, 연 1,000만, 납부세액 한도) − 기타공제. 음수면 환급
calcSimplifiedVat공급대가, 업종별 부가가치율, 매입 공급대가공급대가 × 부가가치율 × 10% − 매입 0.5% − 카드공제. 4,800만 미만이면 납부면제. 환급 없음
세율표는 2025 귀속까지 확인된 값이다. 카드발행세액공제는 공제율과 적용 기한이 일몰 연장 여부에 따라 바뀔 수 있으므로, 신고 전에 국세청 고시로 확인한다.

4. F안 상세: 파일 업로드 분석

처리 흐름

파일 로드 (files.ts): xls/xlsx/HTML은 SheetJS로 시트별 CSV로 바꾼다. CSV는 UTF-8을 시도하고 실패하면 EUC-KR로 읽는다. PDF와 이미지는 base64 블록으로 넣는다. 파일당 30MB 제한.
마스킹 (mask.ts): 텍스트 자료에서 주민·외국인번호, 카드번호, 계좌·사업자·전화번호 형태를 마스킹한다. PDF와 이미지는 마스킹하지 못하므로 경고를 표시한다.
분석 (assistant.ts): Tool Runner가 Claude와 도구 호출을 반복한다(최대 20회). Claude가 계산 도구로 세액을 얻고, 마지막에 submit_report를 호출한다.
리포트 (report.ts): 확신도와 절세액 순으로 정렬한 Markdown과 JSON을 out/에 저장한다.

Claude 호출 설정

설정값이유
모델claude-opus-5-5세법 해석과 다단계 판단 품질
efforthigh이 모델의 기본값(medium)보다 깊게 판단
thinking생략 (adaptive 자동)이 모델은 thinking을 끌 수 없음
fallbacks"default"안전 분류기 오탐 시 서버에서 다른 모델로 자동 재시도
max_tokens / iterations16,000 / 20도구 루프 상한
최종 출력submit_report 도구 (zod 스키마)이 모델은 강제 tool_choice를 지원하지 않으므로, 프롬프트로 유도하고 스키마로 검증

5. 확장 설계 (B · A · C)

B · CDP 로컬 에이전트

  • Chrome을 --remote-debugging-port로 띄워 직접 로그인
  • Playwright connectOverCDP로 현재 탭에 연결
  • 도구: read_page(어댑터 JSON), 계산 도구, highlight_field
  • WebSquare iframe 대응: 모든 프레임 순회
  • 터미널에서 대화형 질의응답

A · Chrome Side Panel

  • Manifest V3, side_panel 사용, content script는 all_frames로 주입
  • B의 화면 어댑터 재사용 (packages/hometax-adapter)
  • API 키는 확장에 두지 않고 로컬 프록시(localhost)에서 호출
  • suggest_input은 내가 승인한 뒤에만 값을 입력
  • 압축 해제 확장으로 로드, 스토어 배포 없음

C · Computer use

  • computer_toolset_20260801 (Opus 5.5 기준)
  • 스크린샷 읽기만 허용, 클릭·입력 액션은 차단
  • 어댑터가 없는 화면의 보조 판독용
  • 느리고 비싸므로 필요한 화면에만 사용

6. 안전장치와 개발 규칙

구분규칙
제출어떤 안도 신고 제출 버튼을 누르지 않는다. 최종 제출은 사용자가 한다
입력홈택스 화면에 값을 넣는 동작(A·B)은 사용자가 승인한 뒤에만 실행한다
계산세액과 절세액은 tax-engine 결과만 쓴다. LLM은 암산하지 않는다
개인정보텍스트는 마스킹한 뒤 전송한다. 원본 전송(PDF·이미지)은 경고한다
저장소input/, out/, .env, 엑셀·PDF는 gitignore. 비밀값은 커밋 금지
대화 로그.claude/hooks/conv-log.cjs가 매 응답마다 ConvLogAi.md를 커밋하고 push한다. 프롬프트에 실제 세무자료나 키를 붙여넣지 말 것
테스트세율이나 계산 로직을 바꾸면 engine.test.ts에 케이스를 추가한다. npm test, npm run typecheck 통과 필수
배경과 로드맵은 계획안 참고.
